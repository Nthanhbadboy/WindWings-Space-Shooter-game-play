## 1. Vì sao cần báo cáo này

165 dừng đúng chỗ gọi `Box_Rewards.SetNumber(rewards.number × count)`; 164 dừng ở `SetInfo(box, icon, number, _isCards, scale, null)` và để mở câu "hàng thưởng trông thế nào". Phạm vi: `Box_Rewards` (bảng field + 7 method) và cách popup gọi nó. **Không** mở lại giá ba dải (158), chuỗi popup (159), cây dải (160), bộ đếm đã bán (156), PlayerPrefs (162), lambda (163), `Shop_Pack`/`EventRewards`/9 pad (164), widget số lượng (165).

## 3. `SetNumber(int)`: số → text + bề rộng border

Thứ tự thực thi (20001584):

```asm
20001584  …                     ; this = x20, number = w19
20001632  cmp  w19, #1          ; số dương?
20001636  str  w19, [x20, #0x64]; this.number = number
20001640  b.lt  20001780        ; n < 1  -> nhánh "không số"
20001656  bl   #0x1313434       ; GetShortNumber(number)   = 20001844
20001676  bl   #0x1fe4084       ; String.Concat(prefix_cell[0x2ade140], shortened)
20001712  blr  x10              ; textNumber.set_text(concat)   (slot 0x518/0x520)
20001740  ldr  s2, [x9, #0xc78] ; rodata 0x756c78  (độ nới thêm)
20001744  add  w8, w8, #1       ; độ dài chuỗi + 1
20001752  fmul s0, s0, s3       ; xChar * (len + 1)
20001756  fadd s0, s0, s2       ; + 0x756c78
20001760  fmov s2, #2.00000000
20001764  fminnm s0, s0, s2     ; clamp ≤ 2.0
20001772  bl   #0x278ae34       ; borderNumber.set_size(Vector2(s0, s1 = yChar))
```

Nhánh `n < 1` (20001780…):

```asm
20001780  ldr  x0, [x20, #0x20] ; textNumber
20001804  blr  x9               ; set_text(null)  -> không in số 0
20001816  cmp  w19, #0
20001824  cset w1, gt           ; enabled = (n > 0)
20001836  bl   #0x2768778       ; borderNumber.enabled = …
```

Ba điểm đáng pin:

- **Bề rộng border là một hàm của số ký tự**, không phải của giá trị số: `xChar·(len+1) + 0x756c78`, chặn trên **2.0**, còn `y` giữ nguyên `yChar`. Nghĩa là "1200" và "9999" cùng độ rộng, nhưng "12" hẹp hơn "1200".
- **`SetNumber` chỉ ghi đúng một field instance** (`0x64`) — verifier kiểm `writes_count_like_fields == ['0x64']`.
- **`count = 0` không hiện "0"**: text bị xoá và border bị tắt. Đây là mảnh còn thiếu của 165: khi `OnChange` tính ra `count = 0` (slider ở 0), hàng thưởng *biến mất số* thay vì hiện `0`.

## 4. `GetShortNumber(int)`: bốn bậc, ba ngưỡng nhúng trong code

Ba ngưỡng được dựng bằng cặp `mov` + `movk` **ngay trong thân method** (không phải dữ liệu):

| Ngưỡng | Lệnh | RVA |
|---|---|---|
| **999.999** = `0x000F423F` | `mov w8, #0x423f` + `movk w8, #0xf, lsl #16` | 20001920 / 20001924 |
| **99.999.999** = `0x05F5E0FF` | `mov w8, #0xe0ff` + `movk w8, #0x5f5, lsl #16` | 20001944 / 20001948 |
| **999.999.999** = `0x3B9AC9FF` | `mov w8, #0xc9ff` + `movk w8, #0x3b9a, lsl #16` | 20001960 / 20001964 |

Bốn đường ra:

| Khoảng | Đường | RVA | Chia bởi | Format (cell tĩnh) |
|---|---|---|---|---|
| `n ≤ 999.999` | `Int32.ToString()` (**34616120**) | 20002012 | — | — |
| `≤ 99.999.999` | `Single.ToString(fmt)` (**34697908**) | 20002028 | `fmov s1, #1000.0f` (20002036, `0x447a0000`) | `0x2ae1390` |
| `≤ 999.999.999` | `Single.ToString(fmt)` | 20002068 | rodata **`0x7570b8`** | `0x2ae1398` |
| `> 999.999.999` | `Single.ToString(fmt)` | 20001980 | rodata **`0x756df8`** | `0x2ae1388` |

Cả ba đường rút gọn hội về **một** call-site `bl #0x21172b4` (`Single.ToString(string)`) qua đuôi chung 20002096 / 20002100 / 20002104. Hệ quả: **số mà người chơi thấy trên hộp không phải `number`**, mà là `number` sau khi rút gọn — nên `number × count` của 165 có thể hiện dạng rút gọn.

## 5. `SetInfo(...)`: thứ tự ghi, và `_strBonus = null` nghĩa là gì

Đăng ký tham số ngay đầu method (19990656): `x24 = _boxSpr`, `x23 = _iconSpr`, `w19 = _number`, `w22 = _isCards`, `v8 = _scaleIcon`, `x21 = _strBonus`.

```asm
19990740  str  w19, [x20, #0x64]   ; this.number = _number
19990756  bl   #0x278ad60          ; boxRenderer(0x38).set_sprite(_boxSpr)
19990776  bl   #0x278ad60          ; iconRenderer(0x40).set_sprite(_iconSpr)
19990816  bl   #0x2789940          ; icon.transform.localScale = (v8, v8, 1.0)
19990844  bl   #0x2781804          ; objCards(0x48).SetActive(_isCards & 1)
19990896  bl   #0x1fed004          ; String.IsNullOrEmpty(_strBonus)
19990960  …    blr x10             ; (nhánh khác rỗng) textBonus.set_text(_strBonus)
19991028  mov  w1, #1 / 19991036   ; (nhánh khác rỗng) obj cha.SetActive(true)
19990952  mov  w1, wzr / 19991036  ; (nhánh rỗng)       obj cha.SetActive(false)
19991068  b    #0x1313330          ; tail-call SetNumber(_number)
```

- `_isCards` không dùng trực tiếp mà qua `and w1, w22, #1` — badge thẻ là một `GameObject` bật/tắt, không phải sprite đổi.
- `_scaleIcon` chỉ tác động **x và y**; trục `z` luôn `1.0` (`fmov s2, #1.00000000`).
- **Popup luôn truyền `_strBonus = null`**: trong `SetEventRewardTabs` hai lệnh cuối trước `b #0x1310880` là `mov x5, xzr` / `mov x6, xzr` (22837696 / 22837700). Với `null`, `String.IsNullOrEmpty` trả true ⇒ nhánh **rỗng** chạy ⇒ object cha của `textBonus` bị `SetActive(false)`; nhánh in text (19990960) chỉ chạy khi chuỗi khác rỗng.
- `SetInfo` **không** gọi `SetNumber` bằng `bl` mà bằng `b` (tail-call) — nghĩa là `SetNumber` là việc cuối cùng, không có gì chạy sau nó trong `SetInfo`.

## 6. `SetGrayScale(bool)`: cùng một shader float với "thiếu medal" của 165

```asm
20002308  tst   w20, #1            ; gray?
20002312  fmov  s0, wzr            ; 0.0
20002316  fmov  s1, #1.00000000    ; 1.0
20002320  fcsel s8, s1, s0, ne     ; gray -> 1.0, else 0.0
20002332  ldr   x20, [x20, #0xea8] ; cell 0x2adbea8 (tên property)
20002348  bl    #0x276a2b4         ; iconRenderer.material.SetFloat(name, s8)
20002384  bl    #0x276a2b4         ; boxRenderer.material.SetFloat(name, s8)
20002408… loop qua grayRenderers   ; từng phần tử .material.SetFloat(name, s8)  (20002456)
```

Cell `0x2adbea8` **chính là** cell mà 165 đo được ở cờ "thiếu medal" (`fcsel s0, s1, s0, lt` → 1.0 khi `medal < price × count`). Vậy hai thứ chỉ là một: icon bị **làm xám** đúng lúc không đủ medal; 166 chỉ ra thêm là nó xám cả **box** và **mọi `grayRenderers[i]`**, không chỉ icon.

## 7. Hai helper nhỏ và `.ctor`

- `SetBoxSprite(Sprite)` (20002124): `ldr x0, [x0, #0x38]` rồi `b #0x278ad60` — chỉ là tail-call `boxRenderer.set_sprite`.
- `SetIconSprite(Sprite, float)` (20002152): set sprite cho `0x40` rồi `transform.set_localScale((scale, scale, 1))` (20002228).
- `.ctor()` (20002504): `adrp x8, #0x757000` + `ldr d0, [x8, #0xbb8]` → `0x757bb8`; `str d0, [x0, #0x58]` ghi **8 byte** phủ `0x58` (xChar) **và** `0x5c` (yChar); rồi `b #0x2782ba0` (`MonoBehaviour..ctor`). Nghĩa là hai float bắt đầu bằng hai nửa của **cùng một** double, không phải hai literal riêng.

## 9. Giới hạn và open item

1. **Tên property shader sau cell `0x2adbea8`** — cell chứa con trỏ chuỗi runtime, literal không nằm trong raw ⇒ `MODEL_NOT_MEASURED runtime`.
2. **Ba chuỗi format** `0x2ae1388 / 0x2ae1390 / 0x2ae1398` (và prefix `0x2ade140`) là con trỏ chuỗi runtime ⇒ không biết `GetShortNumber` in ra `1.2K` hay `1.2` ⇒ `MODEL_NOT_MEASURED runtime`.
3. **Hai float `.rodata`** `0x756df8` và `0x7570b8` (ước chia cho hai bậc cao) — không có `.so` trong sandbox nên không đọc được byte ⇒ `MODEL_NOT_MEASURED runtime`.
4. **`xChar`/`yChar` thực tế** — một double `0x757bb8` cũng nằm trong `.rodata` chưa pin; chỉ biết hai float là hai nửa của nó ⇒ `MODEL_NOT_MEASURED runtime`.
